# JEBML

Matroska muxer/demuxer for the BRTS project.

The modifications are just for better integration with BRTS and are not really intended for general use.


```xml
<dependency>
    <groupId>org.brts</groupId>
    <artifactId>jebml</artifactId>
    <version>2.4.0</version>
</dependency>
```
